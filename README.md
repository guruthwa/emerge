## 🚀 Quick Start for Deployment

### Deploy to GitHub Pages

1. **Fork or clone this repository**
   ```bash
   git clone YOUR_REPO_URL
   cd YOUR_REPO_NAME
   ```

2. **The `docs` folder is ready for deployment!**
   - All built files are in `/docs` folder
   - `.nojekyll` file is included

3. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Deploy Guruthwa Study Café website"
   git push origin main
   ```

4. **Enable GitHub Pages**
   - Go to Repository **Settings** → **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** → Folder: **/docs**
   - Click **Save**

5. **Access your site**
   - URL: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

📖 **Detailed deployment guide**: [GITHUB_PAGES_DEPLOYMENT.md](GITHUB_PAGES_DEPLOYMENT.md)

## 🔧 Development

### Prerequisites
- Node.js 16+
- Yarn package manager

### Local Development
```bash
cd frontend
yarn install
yarn start
```

### Build for Production
```bash
cd frontend
yarn build
```

The build output will be in `frontend/build/` folder.
